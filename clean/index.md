###### Clean code requires discipline and the application of many small techniques, guided by a well-developed “code-sense.” Some developers naturally possess this intuition, while others must work to acquire it. This sense helps identify good and bad code and provides a strategy for refining messy code into clean, maintainable code.

###### The ratio of time spent reading vs. writing is well over 10:1. We are constantly reading old code as part of the effort to write new code.  
###### Because this ratio is so high, we want the reading of code to be easy, even if it makes the writing harder. Of course there’s no way to write code without reading it, so making it easy to read actually makes it easier to write.

###### **The Boy Scout Rule** states, you Leave the campground cleaner than you found it.
